# 星航 · 初步构想

**星航是一款在球面棋盘上展开的抽象策略游戏。所有棋子完全同构，没有预设的身份、等级或兵种；它们通过移动、相遇、连接与分离，形成不同的合作形态，一起探索未知的世界。**

它延续 Polyclash 与星逐（Astrial）的球面世界，但尝试把行动从“在空处落下一颗棋子”，拓展到“调动已有的棋子，重新组织彼此的关系”。它借鉴 chess 的移动与局面变化，而不沿用兵种分化与攻王的框架；后续探索也保留落子带来的布局乐趣。

本仓库目前记录设计构想，尚未实现可玩的游戏。以下内容包含设计方向与当前探索约束，尚不是完整定稿的对局规则。

## 一个没有边角的世界

星航的舞台暂定沿用扭棱十二面体及其细分结构。这个封闭的球面没有天然的边角，也没有永远安全的后方。不同位置的连接方式，为行动与合作提供不同的条件。

球面不仅是一种视觉形式，也希望成为游戏体验的一部分：从一个方向看似遥远的伙伴，可能通过另一条路径相遇；一次局部的移动，也可能改变更大范围的联系。

当前选择让棋子位于交叉点上，而不是四边形面上。具体走法及其与球面连接结构的关系，仍需继续探索。

## 相同的棋子，不同的关系

每颗棋子遵循相同的基本规则。它的作用不来自“它是什么”，而来自“它在哪里，与谁相邻，正在参与什么”。

同一颗棋子，可以成为连接两群伙伴的桥梁，也可以参与一个稳定的结构；可以暂时离开集体，开辟新的路径，也可以通过让出位置，为其他棋子创造行动空间。这些不是固定角色，而是随局面变化的临时作用。

我们希望合作不只有聚集这一种形态。接应、分散、轮换、留空、等待与重新连接，都可能有自己的价值。**好的结构不只是坚固，也应该容许变化；有意义的行动不只是前进，也可能是退让。**

## 从关系中产生行动的可能

星航值得探索的一个核心方向是：棋子之间的关系，能否产生单颗棋子独自无法获得的行动机会？

例如，伙伴的位置可能使一次移动成为可能，一种排列可能打开新的通路，而结构的重组可能让探索向更远处延伸。这些只是设计线索，尚不是确定规则。

我们不希望“合作”只是提高攻击效率的工具，也不希望棋子越聚越多就必然越强。关系应当带来机会，同时伴随取舍：维持一个结构，可能限制流动；走向新的区域，也可能暂时失去接应。

## 有张力，但不以拼杀为唯一归宿

星航可以保留对弈中的判断、竞争与意外，但不预先认定，消灭对手就是最终目标。当前明确不吃子，不以消灭对手作为行动方式。

“中和”在这里更适合作为设计的方向，而不是强制玩家和睦或追求平局：游戏应让玩家体会，局部的强大未必等于整体的良好，持续扩张未必优于适度停留，暂时让步也可能创造更丰富的未来。

同一方棋子之间的合作，与对局双方之间的关系，需要分别打磨。仅仅让棋子同构，并不会自动产生共存的体验；胜负与反馈机制，也应为克制、平衡和探索留下真实的价值。

## 希望留给孩子的体验

星航不打算把某种道理直接写成答案，而希望让孩子在行动中发现：相同的个体，可以通过不同的关系创造不同的可能；合作不要求始终一致，独立探索也不意味着与伙伴失去联系。

**“我能怎样行动”与“我们能怎样一起行动”，是同一个世界里的两个问题。**

## 保持开放的设计问题

以下整理来自 [PR #1 的后续设计评论](https://github.com/mountain/xing-hang/pull/1#issuecomment-6675332911)。其中既有当前约束，也有探索性的初步回答；它们还不足以构成完整的对局规则。

### 当前约束与探索起点

- **参与方：**先从两方开始探索，不排除三方游戏的可能性。
- **棋子位置：**棋子位于交叉点上。
- **行动框架：**轮流落子或者走子，落子受棋子数量上限约束；上限数值与具体走法尚未确定。
- **吃子：**不吃子。

这些约束延续棋子同构、通过关系创造行动机会的方向，但并没有规定具体的移动方式，也没有解决所有布局与评价问题。

### 棋子数量与行动可能性

棋子数量希望成为一个可以研究的组合论问题：以双方为例，什么样的棋子数量能让走子产生最大的可能数？这里的“可能数”尚需定义，不能先当作一个已经明确的优化指标。

评论以两个极端情形提供直觉：“一个子最多只有 5 个可能性”，而“全部布满盘面可能性为 0”。这两点应保留为待检验的观察，而非已证明结论；尤其前者需要先明确走法、所在交叉点的连接情况，以及“可能性”的计数口径。后续需要说明，所计数的是某一局面下的合法走子，还是走子后产生的不同局面等，再讨论棋子数量与行动空间的关系。

因此，目前不确定棋子数量，也不能给出落子上限的具体数值。

### 从空棋盘开始的布局设想

围棋的布局乐趣提供了一个探索方向：**从空棋盘开始，轮流落子或者走子。**可以将落子想象为飞船把探索小分队降落在未知星球，一个小分队对应一颗棋子。

这使布局与后续调动都有机会成为探索的一部分。空棋盘开局仍是一种候选方案，并非已经确定的初始布局；具体走法及关系如何产生新的行动机会，也仍待明确。

### 水源、资源与“活”的设想

未知信息可以考虑引入，但尚未决定。一个初步设想是在棋盘上引入固定或者随机的水源、水域，只有围绕水才可以建立城市。类似围棋，可以探索“活”的概念：一个棋子自带一定的资源，但必须找到水源才可以活。

这仍是探索线索，不是资源或城市规则。水源如何设置、是否可见，棋子自带资源的具体含义与是否消耗，以及“找到水源”“建立城市”“活”各自如何判定，都尚未明确；也不能把未“活”的棋子直接解释为会被移除，从而与不吃子的约束混淆。

“探索未知”首先是一种体验目标，并不意味着已经决定加入迷雾、随机事件或隐藏地图。

### 结束与评价的候选方向

评论提出两个候选评价方向：揭露、探索的最大面积，或者活的城市的最大面积。它们尚未形成终局条件或计分公式，也没有决定如何取舍。

后续需要明确面积的含义与计算方式，以及在什么条件下结束一局，再讨论这些方向如何体现探索、合作与布局的价值。

星航此刻最重要的核心是：**在一个没有边角的世界里，让平等的棋子通过不断变化的关系，发现共同前行的多种可能。**
